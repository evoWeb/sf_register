# Security Policy

## Supported Versions

Supported are only the last to major versions with their branch, the develop branch and main branch.

| Version | Supported          |
|---------|--------------------|
| 14.x    | :white_check_mark: |
| 13.x    | :white_check_mark: |
| 12.x    | :x:                |
| 11.x    | :x:                |
| older   | :x:                |

## Reporting a Vulnerability

In case you find a security issue do not open an issue in GitHub but email security@evoweb.de
